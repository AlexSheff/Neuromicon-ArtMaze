## 3. Audio Graph Audit (`TZ.md` §2.3)

- **File:** `src/systems/audio/spatialAudioSystem.ts:11–266`.
- **Current Architecture:**
  - `AudioContext` is lazily created in `ensureAudioContext()` (`lines 25–44`) when the user clicks the HTML `Enter` button (`src/App.tsx:31`) or clicks the canvas (`src/ui/LabyrinthViewport.tsx:427`).
  - Synthesized chime cues (`triggerChime`, `lines 243–262`) create a transient `OscillatorNode` → `GainNode` → `this.masterGain` → `this.ctx.destination`.
  - Streamed room tracks (`playRoomSoundtrack`, `lines 180–231`) use an `HTMLAudioElement` (`new Audio()`) with direct `audio.volume = this.volume` without routing through `AudioContext.createMediaElementSource` or dedicated `music` / `ambient` / `sfx` buses or a `DynamicsCompressorNode` limiter.
  - **Gap to close in §5:** Create `src/systems/audio/mixer.ts` owning `[music bus]`, `[ambient bus]`, `[sfx bus]` → `[master gain]` → `[limiter (DynamicsCompressorNode)]` → `destination`, with perceptual `v²` gain mapping and `setTargetAtTime` (`40 ms`).

## 4. Pause, Mute & Volume Control Audit (`TZ.md` §2.4)

- **Pause:** No pause system or pausable game clock existed prior to `TZ.md`. `LabyrinthViewport.tsx:369` passed wall-clock `dt` directly to `engine.stepAndRender(dt, ...)`.
- **Volume & Mute:** A single linear volume slider (`0..1`) and mute toggle existed inside the desktop `Z` drawer (`src/ui/LabyrinthViewport.tsx:933–992`). It was not persisted in `PlayerState`, did not have separate `master` / `music` / `ambient` / `sfx` sliders, and was a 2D DOM overlay rather than a world-locked 3D VR panel.
