# ROOM_0042 — The Room That Remembers

## Description

A room that mutates across visits. On Visit 1, only the Chronicle Stone is present and `returnAllowed` is `false`. Leaving through a Void and returning increments `visitCount`, materializing the Chair (`Visit 2`) and the Nocturnal Sundial (`Visit 3`), while unlocking the Memory Fold door (`RH`).
