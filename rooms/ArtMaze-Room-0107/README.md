# ROOM_0107 — The Archivist's Mirror

## Description

Reached via rabbit-hole transitions (`SHADOW_WITHOUT_OBJECT` in `ROOM_0000` or `REFLECTION_MISMATCH` in `ROOM_0001`). Contains the canonical Mirror (`THE_ARCHIVIST`) where the player may `ACCEPT`, `REJECT`, or `RETURN`. Accepting the Archivist state reveals the threshold toward `ROOM_1149`.
