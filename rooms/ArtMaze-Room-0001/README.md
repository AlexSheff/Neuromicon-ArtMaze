# ROOM_0001 — The Hall of Unseen Reflections

## Description

A gallery bisected by a monumental mirror surface. Two stone monoliths stand in the room, but the eastern monolith has no reflection. Observing the discrepancy unlocks a hidden rabbit-hole transition (`RH`) to `ROOM_0107`.
